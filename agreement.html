🔒 Приватность и безопасность

Анализ файлов выполняется исключительно на стороне клиента (в браузере). Конфиденциальные данные не покидают ваш компьютер.

1. Предмет соглашения

Steam Checker — бесплатный инструмент для локального анализа данных Steam. Администрация обеспечивает корректную работу алгоритмов извлечения SteamID из файлов.

2. Безопасность и защита данных

Обработка данных изолирована в браузере. Никакие файлы, куки, токены или идентификаторы не передаются на внешние серверы и не сохраняются в базах данных. Авторизация через Steam OpenID происходит через официальный сервис Valve.

3. Легальное использование

Используя данный инструмент, вы подтверждаете, что анализируете только собственные файлы или файлы, к которым имеете законный доступ.

4. Функции администраторов

Авторизованные администраторы проекта UnionTeams имеют доступ к расширенным функциям платформы. Данные администраторов получаются из публичного API UnionTeams.

5. Отказ от ответственности

Сервис предоставляется «как есть». Пользователь самостоятельно отвечает за использование полученных результатов.
