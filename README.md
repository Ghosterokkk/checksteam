# STEAM CHECKER — safe implementation

Это стилистически близкий к загруженной записи демо-сайт с тёмной чёрно-красной темой. Разделы **«Сканер файлов»**, **«Вручную / Извлечь из текста»** и **«Пути Steam»** не добавлены.

## Авторизация Steam

Форма логина Steam на стороннем сайте специально не копируется и не принимает пароль. Кнопка **«Войти через Steam»** переводит пользователя на `https://steamcommunity.com/openid/login`, а сервер проверяет ответ Steam через `check_authentication`. Steam прямо документирует OpenID как способ аутентификации SteamID без передачи сайту имени пользователя и пароля.

## Запуск

```bash
npm install
BASE_URL=http://localhost:3000 npm start
```

Открыть `http://localhost:3000`.

Для продакшена задайте HTTPS-адрес в `BASE_URL` и используйте серверную сессию вместо возврата SteamID в query string.
