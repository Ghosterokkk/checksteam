STEAM CHECKER — версия 5.0

В редакторе обучения исправлено:
- изменение межстрочного интервала применяется сразу при вводе значения;
- кнопки уменьшения и увеличения интервала изменяют выбранный блок;
- значение интервала не перезаписывается прежним во время редактирования;
- цвет текста и цвет фона определяются по фактическому оформлению выделенного фрагмента;
- если в выделении несколько цветов, это отображается в подсказке соответствующего поля.

Для обновления замените файлы сайта содержимым архива и опубликуйте изменения на GitHub Pages. Cloudflare Worker для этих изменений обновлять не требуется.
