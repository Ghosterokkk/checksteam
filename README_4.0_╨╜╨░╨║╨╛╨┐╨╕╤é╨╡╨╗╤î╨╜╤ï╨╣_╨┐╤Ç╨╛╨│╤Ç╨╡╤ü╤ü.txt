STEAM CHECKER 4.0 — накопительный прогресс обучения Intern

Изменения:
- Прогресс считается относительно высоты именно материалов курса, а не всей страницы с блоком подтверждения.
- На сервер отправляется только новый максимум прогресса. Существующее значение никогда не уменьшается.
- Сохранение выполняется после прокрутки, при скрытии вкладки, закрытии/уходе со страницы.
- Добавлен пересчёт при изменении размеров материалов (например, после загрузки изображений).
- В таблице управления Интернами показывается сохранённый серверный процент.
- После подтверждения обучения сервер фиксирует 100%.

Установка:
1. Обновить файлы GitHub Pages содержимым архива.
2. В Cloudflare Worker заменить код файлом steam-auth-cloudflare/worker.js и нажать Deploy.
3. Не удалять D1 binding, секреты и переменные окружения.
4. Обновить страницы с очисткой кэша (Ctrl+Shift+R).

Важно: код проверен синтаксически, но изменения не развёрнуты на вашем GitHub Pages/Cloudflare и требуют публикации.
